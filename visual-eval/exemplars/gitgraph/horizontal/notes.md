A Git Flow release history for a web shop, drawn as a horizontal git branch graph: time runs left to right and each branch has its own lane, with main on top. It is the same history as the vertical exemplar. `main` is tagged v2.3.0. `develop` branches from it, and a `feature/saved-carts` branch grows off develop. A `hotfix/2.3.1` branch fixes a refund bug and is merged into main as v2.3.1 and back into develop. The feature is then merged, and `release/2.4` is cut, polished, merged into main as v2.4.0 and back into develop. Branch graphs have no formal standard. This variant follows the teaching convention of the Pro Git book's branching figures, the Atlassian Git tutorials, the default Mermaid `gitGraph` layout and the GitHub network graph.

Why it works as the exemplar for this variant:

- Lanes are stacked top to bottom from long-lived to short-lived (main, hotfix, release, develop, feature). Each lane has faint alternating bands and its branch name as a coloured pill in the left gutter. Branches still alive at the end (main, develop) are named again at their tip.
- Columns follow ancestry: a commit sits one column right of its latest parent, so unrelated work on different branches shares a column and the drawing stays compact.
- A fork drops or rises out of its parent commit and settles into the new lane. A merge runs along its own lane and turns into the merge commit, in the colour of the branch being merged. Every curve meets a commit vertically, and lines pass only through their own commits.
- Commit messages stay horizontal. A message fits on one line or is split into two balanced lines, and it is set above or below the dot on whichever side no line leaves from. When lines leave from both sides, it sits below and to the right. Tags are white outlined pills stacked on the commit's clear side, so text never crosses a line or other text.
- Marker shapes match the vertical variant: a filled dot is an ordinary commit, a hollow ring is a merge commit, and a filled square is a highlighted commit. Merge messages are grey, and the palette and legend are the same as in the vertical variant.

Palette: ink #0F172A, muted #475569, faint #64748B, rule #94A3B8, lane band #F8FAFC, paper #FFFFFF; lanes main #2563EB, hotfix #DC2626, release #7C3AED, develop #D97706, feature #059669; tag outline #334155.
