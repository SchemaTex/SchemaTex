## Why this layout is different

The DSL is still a plain netlist: shared node names define connectivity, and the 555 uses its documented eight-pin order. The renderer recognizes the astable from those nets rather than from labels such as `R1` or `C1`, then places the charge/discharge network beside the timer and the LED branch on the output side.

If the topology is incomplete or includes extra ambiguous parts, the renderer uses the generic schematic layout. It never forces a circuit into this arrangement merely because a component happens to be a 555 timer.
