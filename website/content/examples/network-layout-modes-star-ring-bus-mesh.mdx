## Scenario

Network examples should prove that layout is semantic, not incidental. This one uses `layout: star`, where the gateway and access switch form the center and endpoints fan around them.

## Annotation key

- `layout: star` selects the hub-and-spoke placer.
- Link annotations carry VLANs, speed, and PoE.
- The same device/link model can be rendered with other layouts in companion examples.
