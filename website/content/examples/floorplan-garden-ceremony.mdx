## What this shows

Each row is one `arc chair` statement — count, center, radius, and the 20°–160° sweep — with every chair rotated to face the center. Capacity changes are a `count` edit; the validator's oriented-box collision test keeps adjacent chairs honest even though they're all rotated differently.

This is the "Semi-Circle Wedding Seating" request class verbatim: the input arrives as a chair count and a focal point, which is exactly what the arc primitive takes.
