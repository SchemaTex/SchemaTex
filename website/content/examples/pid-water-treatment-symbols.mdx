## What this example proves

The process meaning stays in the topology and named ports, not in coordinates or colors. The filter's main inlet/outlet, chemical injection, backwash, and drain connections remain distinct. The outlet valve uses the same `valve_control` body as a pneumatic loop, but composes a motor actuator and therefore expects an electric controller signal.

If an agent writes a port such as `F-101.drian`, SchemaTex keeps a partial preview visible but reports `PID_UNKNOWN_PORT`; it no longer silently routes the line through an unrelated default port.
