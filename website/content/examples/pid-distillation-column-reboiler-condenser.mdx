## Scenario

Distillation columns are a canonical P&ID use case because the physical process and the control loops must be legible together. This example shows the main process path and three instrument bubbles without pretending to be a full plant drawing.

## Annotation key

- `equip` lines select ISO process equipment symbols.
- `line ... from ... to ...` connects equipment ports and carries line tags.
- `inst` declarations create ISA-5.1 instrument bubbles tied to measured equipment. `PI-201` is a local pressure indicator, so it does not promise an unshown transmitter signal.
