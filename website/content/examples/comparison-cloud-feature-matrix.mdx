## What this shows

A straight side-by-side feature table — options across the top, criteria down the side. Cells mix **marks** (`yes` → ✓ green, `partial` → ~ amber) with **free text** (`"up to 90%"`), so one grid carries both capability flags and figures. The option name on each cell line must match a declared `option`; a typo is flagged in the diagnostics rather than silently dropped.
