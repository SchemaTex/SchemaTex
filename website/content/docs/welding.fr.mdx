## À propos des symboles de soudage

Un **symbole de soudage** indique à un fabricant exactement comment souder un assemblage : quel type de soudure, de quel côté, de quelle taille, sur quelle longueur, et avec quelle finition. La notation est un **squelette de ligne de référence** — une ligne horizontale, une flèche de repère pointant vers l'assemblage, et un petit glyphe de symbole de soudure ancré au-dessus ou en dessous de la ligne — normalisée par **AWS A2.4** (États-Unis) et **ISO 2553** (international). Schematex dessine le squelette correct par construction : vous décrivez la soudure, le moteur place chaque glyphe, dimension et symbole supplémentaire.

Il s'agit d'une notation à *squelette fixe*, pas d'un graphe — aucune mise en page n'est à résoudre, ce qui garantit un rendu déterministe à chaque fois.

## 1. Votre première soudure

La légende minimale utile : un en-tête, un assemblage, une soudure côté flèche.

```
welding "Bracket"
joint "bracket to plate" {
  arrow: fillet size=8
}
```

Trois règles couvrent la majorité des usages :

1. Commencez par `welding`, optionnellement `standard: aws | iso-a | iso-b` (par défaut `aws`) et un titre entre guillemets.
2. Chaque assemblage est un bloc `joint "label" { … }`. Placez une soudure sur `arrow:` (côté flèche) et/ou `other:` (autre côté).
3. Une spécification de soudure est un type suivi de dimensions en `clé=valeur` — `fillet size=8`, `vgroove angle=60 root=3`.

---

## 2. Côtés — flèche, autre, les deux

Un assemblage est soudé du côté flèche, de l'autre côté, ou des deux.

```
joint "double fillet" {
  both: fillet size=6        # même soudure des deux côtés
}
joint "asymmetric" {
  arrow: fillet size=8       # côté flèche uniquement
  other: vgroove angle=60    # soudure différente de l'autre côté
}
```

- **AWS** (par défaut) : le glyphe côté flèche se dessine **en dessous** de la ligne de référence, le glyphe de l'autre côté **au-dessus**.
- **ISO-A** (`standard: iso-a`) : une **ligne d'accompagnement en tirets** apparaît ; la soudure côté flèche s'attache à la ligne pleine, la soudure de l'autre côté à la ligne en tirets. Une soudure symétrique `both:` supprime la ligne en tirets.

---

## 3. Types de soudures

| Type | Glyphe | Type | Glyphe |
|------|--------|------|--------|
| `fillet` | triangle | `plug` / `slot` | rectangle |
| `square` | verticales parallèles | `spot` | cercle sur la ligne |
| `vgroove` | V | `seam` | cercle + ligne |
| `bevel` | demi-V | `back` / `backing` | demi-cercle |
| `ugroove` | U | `surfacing` | bosses de rechargement |
| `jgroove` | demi-U | `edge` | hautes verticales |
| `flarev` / `flarebevel` | gorge courbe | | |

Alias : `v`→`vgroove`, `u`→`ugroove`, `j`→`jgroove`, `flare-v`→`flarev`.

---

## 4. Dimensions

Les dimensions se lisent le long de la ligne de référence dans des emplacements fixes.

```
joint "groove" {
  arrow: vgroove angle=60 root=3 throat=12 len=50 pitch=150
}
```

| Clé | Emplacement | Signification |
|-----|-------------|---------------|
| `size=` | à gauche du symbole | jambe de congé / profondeur de gorge / diamètre du trou |
| `throat=` | à gauche, entre parenthèses | gorge efficace `(E)` |
| `len=` | à droite du symbole | longueur de soudure |
| `pitch=` | à droite (avec `len`) | pas de soudure discontinue centre à centre → `len-pitch` |
| `count=` | à droite (ISO) | nombre d'incréments → `count×len (pitch)` |
| `angle=` | à l'ouverture | angle d'ouverture de la gorge (types de gorge uniquement) |
| `root=` | entre le symbole et la ligne | ouverture / jeu en pied de joint |
| `contour=` | au-dessus du symbole | `flush` (barre), `convex`, `concave` (arc) |
| `finish=` | au-dessus du contour | lettre de méthode de finition `G`/`M`/`C`/`R`/`H`/`U` |

## 5. Symboles supplémentaires

```
joint "post base" {
  arrow: fillet size=10
  around            # soudure tout autour — cercle ouvert à la jonction
  field             # soudure en chantier / sur site — drapeau plein pointant vers la queue
  tail: "GTAW; WPS-12"   # procédé / spécification / méthode CND
}
```

## 6. Conformité au standard

Les diagrammes de soudage Schematex implémentent **AWS A2.4:2020** (ligne de référence unique) et **ISO 2553:2019** systèmes A (ligne double pleine + tirets) et B.

- ✅ Catalogue complet de glyphes — congé, gorge carrée / V / biseautée / U / J / flare-V / flare-bevel, trou, fente, point, cordon, envers, support d'envers, rechargement, bord
- ✅ Emplacements de dimensions — taille, gorge `(E)`, longueur, longueur-pas, count×longueur, angle de gorge, ouverture en pied
- ✅ Suppléments — cercle soudure tout autour, drapeau soudure en chantier, queue procédé/spécification/CND, contour + finition
- ✅ Côtés flèche / autre / les deux avec convention par standard
- ✅ Validation lisible par AI des combinaisons type/côté/dimension illicites
- ⏳ Symboles combinés soudure + CND (le CND est du texte de queue aujourd'hui)
- ⏳ Rupture de flèche pour le membre préparé ; décalage de soudure discontinue alternée ; glyphes de pénétration complète / insert consommable

Références :

- American Welding Society (2020). *AWS A2.4 : Standard Symbols for Welding, Brazing, and Nondestructive Examination.*
- ISO 2553:2019. *Welding and allied processes — Symbolic representation on drawings — Welded joints.*

## 7. Grammaire (EBNF)

```text
document  = "welding" ( "standard:" std )? title? NEWLINE joint*
std       = "aws" | "iso-a" | "iso-b"
joint     = "joint" title? "{" directive* "}"
directive = ( "arrow:" | "other:" | "both:" ) weldspec
          | "around" | "field"
          | "tail:" quoted-string
weldspec  = type ( WS key "=" value )*
type      = "fillet"|"square"|"vgroove"|"bevel"|"ugroove"|"jgroove"
          | "flarev"|"flarebevel"|"plug"|"slot"|"spot"|"seam"
          | "back"|"backing"|"surfacing"|"edge"
key       = "size"|"len"|"pitch"|"count"|"angle"|"root"|"throat"|"contour"|"finish"
```
