## Sobre símbolos de soldagem

Um **símbolo de soldagem** informa ao fabricante exatamente como soldar uma junta: que tipo de solda, em qual lado, qual o tamanho, o comprimento e o acabamento. A notação é um **esqueleto de linha de referência** — uma linha horizontal, uma seta líder apontando para a junta e um pequeno glifo de símbolo de solda encaixado acima ou abaixo da linha — padronizado pela **AWS A2.4** (EUA) e **ISO 2553** (internacional). O Schematex desenha o esqueleto correto por construção: você descreve a solda, o mecanismo posiciona cada glifo, dimensão e símbolo suplementar.

Esta é uma notação de *esqueleto fixo*, não um grafo — não há layout a resolver, portanto ela renderiza de forma determinística todas as vezes.

## 1. Sua primeira solda

O menor callout útil: um cabeçalho, uma junta, uma solda no lado da seta.

```
welding "Bracket"
joint "bracket to plate" {
  arrow: fillet size=8
}
```

Três regras cobrem a maior parte do uso:

1. Comece com `welding`, opcionalmente `standard: aws | iso-a | iso-b` (padrão `aws`) e um título entre aspas.
2. Cada junta é um bloco `joint "label" { … }`. Coloque uma solda em `arrow:` (lado da seta) e/ou `other:` (outro lado).
3. Uma especificação de solda é um tipo seguido de dimensões `chave=valor` — `fillet size=8`, `vgroove angle=60 root=3`.

---

## 2. Lados — arrow, other, both

Uma junta é soldada no lado da seta, no outro lado ou em ambos.

```
joint "double fillet" {
  both: fillet size=6        # mesma solda nos dois lados
}
joint "asymmetric" {
  arrow: fillet size=8       # apenas no lado da seta
  other: vgroove angle=60    # solda diferente no outro lado
}
```

- **AWS** (padrão): o glifo do lado da seta é desenhado **abaixo** da linha de referência, o glifo do outro lado **acima**.
- **ISO-A** (`standard: iso-a`): uma **linha companheira tracejada** aparece; a solda do lado da seta se liga à linha sólida, a solda do outro lado à linha tracejada. Uma solda `both:` simétrica suprime a linha tracejada.

---

## 3. Tipos de solda

| Tipo | Glifo | Tipo | Glifo |
|---|---|---|---|
| `fillet` | triângulo | `plug` / `slot` | retângulo |
| `square` | verticais paralelas | `spot` | círculo na linha |
| `vgroove` | V | `seam` | círculo + linha |
| `bevel` | meio V | `back` / `backing` | semicírculo |
| `ugroove` | U | `surfacing` | saliências de reforço |
| `jgroove` | meio U | `edge` | verticais altas |
| `flarev` / `flarebevel` | ranhura curva | | |

Aliases: `v`→`vgroove`, `u`→`ugroove`, `j`→`jgroove`, `flare-v`→`flarev`.

---

## 4. Dimensões

As dimensões são lidas ao longo da linha de referência em posições fixas.

```
joint "groove" {
  arrow: vgroove angle=60 root=3 throat=12 len=50 pitch=150
}
```

| Chave | Posição | Significado |
|---|---|---|
| `size=` | à esquerda do símbolo | perna de filete / profundidade da ranhura / diâmetro do plug |
| `throat=` | à esquerda, entre parênteses | garganta efetiva `(E)` |
| `len=` | à direita do símbolo | comprimento da solda |
| `pitch=` | à direita (com `len`) | passo intermitente centro a centro → `len-pitch` |
| `count=` | à direita (ISO) | número de incrementos → `count×len (pitch)` |
| `angle=` | na abertura | ângulo incluído da ranhura (apenas para tipos de ranhura) |
| `root=` | entre o símbolo e a linha | abertura de raiz / folga |
| `contour=` | acima do símbolo | `flush` (barra), `convex`, `concave` (arco) |
| `finish=` | acima do contorno | letra do método de acabamento `G`/`M`/`C`/`R`/`H`/`U` |

## 5. Símbolos suplementares

```
joint "post base" {
  arrow: fillet size=10
  around            # soldar em volta — círculo aberto na junção
  field             # solda em campo / local — bandeirinha preenchida apontando para a cauda
  tail: "GTAW; WPS-12"   # processo / especificação / método NDE
}
```

## 6. Conformidade com o padrão

Os diagramas de soldagem do Schematex implementam a **AWS A2.4:2020** (linha de referência única) e a **ISO 2553:2019** Sistemas A (linha dupla sólida+tracejada) e B.

- ✅ Catálogo completo de glifos — filete, ranhuras quadrada / V / bevel / U / J / flare-V / flare-bevel, plug, slot, spot, seam, back, backing, surfacing, edge
- ✅ Posições de dimensão — tamanho, garganta `(E)`, comprimento, comprimento-passo, count×comprimento, ângulo de ranhura, abertura de raiz
- ✅ Suplementares — círculo de solda em volta, bandeirinha de solda em campo, processo/especificação/NDE na cauda, contorno + acabamento
- ✅ Lados arrow / other / both com convenção por padrão
- ✅ Validação legível por AI de combinações ilegais de tipo/lado/dimensão
- ⏳ Símbolos combinados de solda + NDE (NDE é texto de cauda atualmente)
- ⏳ Quebra de seta para o membro preparado; deslocamento intermitente escalonado; glifos de fusão completa / inserto consumível

Referências:

- American Welding Society (2020). *AWS A2.4: Standard Symbols for Welding, Brazing, and Nondestructive Examination.*
- ISO 2553:2019. *Welding and allied processes — Symbolic representation on drawings — Welded joints.*

## 7. Gramática (EBNF)

```text
document  = "welding" ( "standard:" std )? title? NEWLINE joint*
std       = "aws" | "iso-a" | "iso-b"
joint     = "joint" title? "{" directive* "}"
directive = ( "arrow:" | "other:" | "both:" ) weldspec
          | "around" | "field"
          | "tail:" quoted-string
weldspec  = type ( WS key "=" value )*
type      = "fillet"|"square"|"vgroove"|"bevel"|"ugroove"|"jgroove"
          | "flarev"|"flarebevel"|"plug"|"slot"|"spot"|"seam"
          | "back"|"backing"|"surfacing"|"edge"
key       = "size"|"len"|"pitch"|"count"|"angle"|"root"|"throat"|"contour"|"finish"
```
