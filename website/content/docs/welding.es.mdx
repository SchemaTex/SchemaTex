## Sobre los símbolos de soldadura

Un **símbolo de soldadura** le indica al fabricante exactamente cómo soldar una junta: qué tipo de soldadura, en qué lado, qué tan grande, qué tan largo y cómo terminarlo. La notación es un **esqueleto de línea de referencia** — una línea horizontal, una flecha de guía apuntando a la junta y un pequeño glifo de símbolo de soldadura ajustado arriba o abajo de la línea — estandarizado por **AWS A2.4** (EE. UU.) e **ISO 2553** (internacional). Schematex dibuja el esqueleto correcto por construcción: describes la soldadura y el motor coloca cada glifo, dimensión y símbolo suplementario.

Esta es una notación de *esqueleto fijo*, no un grafo — no hay diseño que resolver, por lo que se renderiza de forma determinística cada vez.

## 1. Tu primera soldadura

El callout mínimo útil: un encabezado, una junta, una soldadura en el lado de la flecha.

```
welding "Bracket"
joint "bracket to plate" {
  arrow: fillet size=8
}
```

Tres reglas cubren la mayor parte del uso:

1. Comienza con `welding`, opcionalmente `standard: aws | iso-a | iso-b` (por defecto `aws`) y un título entre comillas.
2. Cada junta es un bloque `joint "etiqueta" { … }`. Coloca una soldadura en `arrow:` (lado de la flecha) y/o `other:` (otro lado).
3. Una especificación de soldadura es un tipo seguido de dimensiones `clave=valor` — `fillet size=8`, `vgroove angle=60 root=3`.

---

## 2. Lados — flecha, otro, ambos

Una junta se suelda en el lado de la flecha, el otro lado, o ambos.

```
joint "double fillet" {
  both: fillet size=6        # misma soldadura en ambos lados
}
joint "asymmetric" {
  arrow: fillet size=8       # solo lado de la flecha
  other: vgroove angle=60    # soldadura diferente en el otro lado
}
```

- **AWS** (por defecto): el glifo del lado de la flecha se dibuja **debajo** de la línea de referencia, el glifo del otro lado **encima**.
- **ISO-A** (`standard: iso-a`): aparece una **línea compañera discontinua**; la soldadura del lado de la flecha se adjunta a la línea sólida, la soldadura del otro lado a la línea discontinua. Una soldadura `both:` simétrica suprime la línea discontinua.

---

## 3. Tipos de soldadura

| Tipo | Glifo | Tipo | Glifo |
|---|---|---|---|
| `fillet` | triángulo | `plug` / `slot` | rectángulo |
| `square` | verticales paralelas | `spot` | círculo en la línea |
| `vgroove` | V | `seam` | círculo + línea |
| `bevel` | media V | `back` / `backing` | semicírculo |
| `ugroove` | U | `surfacing` | protuberancias de acumulación |
| `jgroove` | media U | `edge` | verticales altas |
| `flarev` / `flarebevel` | ranura curva | | |

Aliases: `v`→`vgroove`, `u`→`ugroove`, `j`→`jgroove`, `flare-v`→`flarev`.

---

## 4. Dimensiones

Las dimensiones se leen a lo largo de la línea de referencia en ranuras fijas.

```
joint "groove" {
  arrow: vgroove angle=60 root=3 throat=12 len=50 pitch=150
}
```

| Clave | Ranura | Significado |
|---|---|---|
| `size=` | izquierda del símbolo | pierna de filete / profundidad de ranura / diámetro de tapón |
| `throat=` | izquierda, entre paréntesis | garganta efectiva `(E)` |
| `len=` | derecha del símbolo | longitud de soldadura |
| `pitch=` | derecha (con `len`) | paso centro a centro intermitente → `len-pitch` |
| `count=` | derecha (ISO) | número de incrementos → `count×len (pitch)` |
| `angle=` | en la apertura | ángulo incluido de ranura (solo tipos de ranura) |
| `root=` | entre símbolo y línea | abertura de raíz / espacio |
| `contour=` | encima del símbolo | `flush` (barra), `convex`, `concave` (arco) |
| `finish=` | encima del contorno | letra del método de acabado `G`/`M`/`C`/`R`/`H`/`U` |

## 5. Símbolos suplementarios

```
joint "post base" {
  arrow: fillet size=10
  around            # soldar todo alrededor — círculo abierto en la unión
  field             # soldadura de campo / in situ — bandera rellena apuntando a la cola
  tail: "GTAW; WPS-12"   # proceso / especificación / método NDE
}
```

## 6. Conformidad con el estándar

Los diagramas de soldadura de Schematex implementan **AWS A2.4:2020** (línea de referencia única) e **ISO 2553:2019** Sistemas A (línea sólida+discontinua dual) y B.

- ✅ Catálogo completo de glifos — filete, cuadrado / V / bisel / U / J / flare-V / flare-bevel de ranura, tapón, ranura, punto, costura, dorsal, respaldo, recargue, borde
- ✅ Ranuras de dimensión — tamaño, garganta `(E)`, longitud, longitud-paso, count×longitud, ángulo de ranura, abertura de raíz
- ✅ Suplementarios — círculo de soldar todo alrededor, bandera de soldadura de campo, proceso/especificación/NDE en cola, contorno + acabado
- ✅ Lados flecha / otro / ambos con convención por estándar
- ✅ Validación legible por IA de combinaciones ilegales de tipo/lado/dimensión
- ⏳ Símbolos combinados de soldadura + NDE (NDE es texto de cola hoy)
- ⏳ Rotura de flecha para el miembro preparado; desplazamiento intermitente escalonado; glifos de fusión completa / inserto consumible

Referencias:

- American Welding Society (2020). *AWS A2.4: Standard Symbols for Welding, Brazing, and Nondestructive Examination.*
- ISO 2553:2019. *Welding and allied processes — Symbolic representation on drawings — Welded joints.*

## 7. Gramática (EBNF)

```text
document  = "welding" ( "standard:" std )? title? NEWLINE joint*
std       = "aws" | "iso-a" | "iso-b"
joint     = "joint" title? "{" directive* "}"
directive = ( "arrow:" | "other:" | "both:" ) weldspec
          | "around" | "field"
          | "tail:" quoted-string
weldspec  = type ( WS key "=" value )*
type      = "fillet"|"square"|"vgroove"|"bevel"|"ugroove"|"jgroove"
          | "flarev"|"flarebevel"|"plug"|"slot"|"spot"|"seam"
          | "back"|"backing"|"surfacing"|"edge"
key       = "size"|"len"|"pitch"|"count"|"angle"|"root"|"throat"|"contour"|"finish"
```
